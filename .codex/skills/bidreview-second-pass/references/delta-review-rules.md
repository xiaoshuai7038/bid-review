# Delta Review Rules

## Goal

二次复核的目标不是重写首轮结果，而是补充首轮遗漏的新增 finding。

## Workflow

1. 重新读取招标文件和投标文件。
2. 重新建立主体基线。
3. 针对首轮容易漏掉的位置复核：
  - 招标人 / 投标人信息段
  - 开户行和账号段
  - 授权委托页
  - 签字盖章页
  - 承诺函抬头 / 落款
  - 封面
  - 营业执照
  - 资格审查申请书
  - 投标函
  - 投标保证金交纳证明
  - 偏离表
4. 只返回新增 finding。

## Mandatory Checks

- 首轮若只给了泛化“需人工核验主体一致性”，但文档中已有明确字段和值，二次复核必须补成字段级 finding。
- 若同一主体字段在多处出现不同值，必须新增 finding。
- 若字段标签和值类型不匹配，必须新增 finding。
- 若模板文书中的 `致：`、项目名称、招标编号、主体字段填错对象，必须新增 finding。

## Output Rules

- 只输出新增项。
- `requirement_id` 必须复用已有 requirement。
- 不得新增 requirement 编号。
- 如果没有新增项，返回空数组。
